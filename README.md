# Laxit Khanpara — Portfolio

Bold, dark, animated personal portfolio for **Laxit Khanpara** (Software Engineer).

## Stack

- Vite + React + TypeScript
- React Three Fiber / Drei (3D hero)
- Framer Motion (scroll / entrance animation)
- Deploy-ready for **Vercel** (static) or any static host / Render static site

## Develop

```bash
npm install
npm run dev
```

App runs at `http://localhost:5173`.

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Dev server with HMR |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Oxlint |

Edit `src/content.ts` for copy, projects, links, and awards.
